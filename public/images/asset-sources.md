# Game icon sources

These are unmodified Monster Hunter Wilds game icons served by the Monster Hunter Wiki.
The Artian Weapons page identifies the part and ailment glyphs as Wilds icons.

- Artian part (`artian-part.webp`): [Broken Blade / Relic Blade icon](https://monsterhunterwiki.org/images/d/d8/MHWA-Relic_Blade_Icon_Base.webp), shown on the [Artian Weapons page](https://monsterhunterwiki.org/wiki/Artian_Weapons_%28MHWilds%29).
- Poison (`status/poison.png`): [Poison icon](https://monsterhunterwiki.org/images/6/60/MHWA-Poison_Icon.png).
- Paralysis (`status/paralysis.png`): [Paralysis icon](https://monsterhunterwiki.org/images/6/68/MHWA-Paralysis_Icon.png).
- Sleep (`status/sleep.png`): [Sleep icon](https://monsterhunterwiki.org/images/f/ff/MHWA-Sleep_Icon.png).
- Blast (`status/blast.png`): [Blastblight icon](https://monsterhunterwiki.org/images/4/44/MHWA-Blastblight_Icon.png).

The status glyphs are the game's status icons. Elemental blight icons already in
`elements/` remain the source for fire, water, thunder, ice, and dragon.
